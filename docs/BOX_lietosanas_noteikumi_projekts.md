# BOX lietošanas noteikumi (PROJEKTS)

*Projekts apspriešanai. Pirms parakstīšanas pārbaudīt ar grāmatvedi un, ja nepieciešams, ar juristu.*

**1. Vispārīgi**
1.1. BOX ir uzņēmuma teritorijā esoša remonta telpa ar auto pacēlāju HOFMANN, ko īpašnieks ļauj izmantot grupas "BOX" dalībniekiem privāto automašīnu remontam.
1.2. BOX lietošana nav darba pienākums un notiek ārpus darba laika, ja vien nav saskaņots citādi.
1.3. BOX nav paredzēts peļņai. Iekasētā summa tiek izmantota tikai BOX uzturēšanai un attīstībai.

**2. Rezervācija un uzskaite**
2.1. BOX drīkst lietot tikai ar rezervāciju aplikācijā BOX vai, ja BOX ir brīvs, iečekojoties uz vietas.
2.2. Sākot darbu, lietotājs iečekojas, noskenējot QR kodu BOX iekšpusē. Beidzot darbu, viņš izčekojas.
2.3. Auto, kas atstāts BOX vai uz pacēlāja, aizņem BOX. Laiks tiek skaitīts līdz izčekošanās brīdim.
2.4. BOX koda nodošana citiem vai iečekošanās ārpus BOX ir aizliegta. Iečekojoties un izčekojoties aplikācija pārbauda telefona atrašanās vietu.
2.5. Izčekoties drīkst tikai tad, kad auto ir izbraukts un BOX ir brīvs. Ja nākamais lietotājs atrod BOX neatbrīvotu, viņš to ziņo aplikācijā, un iepriekšējam lietotājam laiks tiek skaitīts no viņa iečekošanās līdz brīdim, kad BOX tiešām atbrīvots.

**3. Samaksa**
3.1. Likme ir 2 €/h par faktisko lietošanas laiku, minimums 1 h vienā reizē.
3.2. Summas tiek uzkrātas lietotāja virtuālajā kontā un slēgtas katra mēneša 1. datumā.
3.3. Parādu var nosegt ar darbu BOX labā (tīrīšana, kurināšana, remonts u.c.) pēc vienošanās ar administratoru vai ar skaidru naudu BOX kasē.
3.4. BOX kases ienākumi un izdevumi ir redzami visiem lietotājiem aplikācijā.

**4. Drošība un kārtība**
4.1. Pacēlāju drīkst lietot tikai personas, kuras ir instruētas par tā drošu lietošanu.
4.2. Lietotājs atbild par savu drošību un par bojājumiem, ko nodarījis BOX aprīkojumam.
4.3. Pēc darba BOX jāatstāj tīrs, instrumenti jānovieto savās vietās, un atkritumi un eļļas jāutilizē norādītajā vietā.
4.4. Bīstami darbi (metināšana, degšķidrumi) ir atļauti tikai, ievērojot ugunsdrošības prasības.

**5. Videonovērošana (stāsies spēkā pēc kameru uzstādīšanas)**
5.1. BOX tiks veikta videonovērošana īpašuma aizsardzībai un drošībai. Par to informēs zīme pie ieejas.
5.2. Ierakstus neizmanto darba kvalitātes vērtēšanai. Tiešraidi redz tikai administrators.
5.3. Glabāšanas termiņš un datu pārzinis tiks norādīti atsevišķā paziņojumā.

**6. Pārkāpumi**
6.1. Ja BOX tiek lietots bez rezervācijas vai iečekošanās, vai noteikumi tiek pārkāpti atkārtoti, administrators var bloķēt piekļuvi.
